# Clash Tracker

Clash Tracker is an early-stage, local-first research project for analyzing
user-provided Clash Royale recordings. Its first technical objective is to
determine whether opponent card deployments can be detected reliably without
interacting with or modifying the game.

The project is intentionally limited to offline recordings and test footage at
this stage. It does not automate gameplay, control the game, or provide a live
match overlay.
